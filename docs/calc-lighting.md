# Калькулятор освещённости помещения

**URL:** https://calcal.ru/osveshchyonnost-pomeshcheniya
**Чанк с логикой:** `/_next/static/chunks/387cb267058b45ea.js` (~39 КБ)
**Снято:** 2026-08-19. Заявленная ревизия сайта — 13 июля 2026.

## Что делает

Считает **количество светильников** для комнаты и попутно — месячный расход электроэнергии
и его стоимость. Позиционируется как расчёт по СП 52.13330.2016 (ред. СНиП 23-05-95).

Расчёт полностью клиентский, на каждый ввод пересчитывается `useMemo`. Никаких сетевых
запросов, никакого API — вся справочная база зашита в JS-бандл.

## Входные параметры

| Поле (label в UI) | Тип | Диапазон | По умолчанию | Переменная в бандле |
|---|---|---|---|---|
| Площадь помещения, м² | number | 1–500, шаг 0.5 | 18 | `e` |
| Высота потолков, м | number | 2.0–6.0, шаг 0.1 | 2.7 | `o` |
| Тип помещения | кнопки, 8 шт | — | `living` | `c` |
| Цвет стен | кнопки, 3 шт | — | `light` | `m` |
| Тип лампы | кнопки, 4 шт | — | `led` | `x` |
| Мощность одного светильника, Вт | number | 1–500 | 12 | `g` |
| Часов в день | number | 1–24 | 6 | `b` |
| Тариф, руб/кВт·ч | number | ≥0, шаг 0.1 | 6.5 | `v` |

Плюс 6 пресетов светильников — кнопки, которые просто подставляют `watt` в поле мощности.

**Тип помещения → норма освещённости (лк):**

`nursery` 200 · `hallway` 100 · `garage` 100

**Цвет стен → коэффициент отражения:**
`light` 0.7 · `medium` 0.5 · `dark` 0.3

**Тип лампы → световая отдача (лм/Вт):**
`led` 100 · `fluorescent` 60 · `halogen` 20 · `incandescent` 12

**Пресеты светильников:** Точечный LED 7 Вт/700 лм · LED-панель 60x60 36/3600 ·

## Формула (дословно из бандла)

```js
// поправка на высоту потолка
heightCoeff = 1;
if (h > 2.7 && h <= 3.0) heightCoeff = 1.2;
else if (h > 3.0 && h <= 3.5) heightCoeff = 1.5;
else if (h > 3.5)            heightCoeff = 2.0;

requiredLumens = lux * area * heightCoeff * (0.7 / wallCoeff);
fixtureLumen   = fixtureWatt * efficiency;
fixtureCount   = Math.ceil(requiredLumens / fixtureLumen);
totalWatt      = fixtureCount * fixtureWatt;
monthlyKwh     = totalWatt / 1000 * hoursPerDay * 30;
monthlyCost    = monthlyKwh * tariff;
```

В оригинале множитель по стенам записан как `(1/coeff) / (1/0.7)` — это тождественно
`0.7 / coeff`, то есть светлые стены приняты за базу (коэффициент 1.0), средние дают ×1.4,
тёмные ×2.33.

Возврат `null` (результат не показывается), если `area <= 0 || height <= 0 || fixtureWatt <= 0`.

## Блок «Рекомендация по размещению»

Помимо чисел оригинал рисует схему: сетку в 4 колонки, по плитке на светильник с номером.
Показывается не больше 24 плиток, дальше одна плитка `+N` с остатком. Под сеткой —
подпись «Равномерно распределите N светильников по площади A м²», и при N > 1 добавляется
`(~A/N м² на светильник)`, округлённое до одного знака.

Это единственная выходная величина сверх основного расчёта: `AreaPerFixture`.

## Правила ввода

Живут в обработчиках `onChange`, то есть поле схлопывается к допустимому значению прямо
при наборе. В самом расчёте их нет.

| Поле | Правило |
|---|---|
| Площадь | `max(0, parseFloat(x) \|\| 0)` — снизу 0, **сверху не ограничена**, хотя в разметке стоит `max="500"` |
| Высота | `max(0, parseFloat(x) \|\| 0)` — так же без верхней границы |
| Мощность | `max(1, parseFloat(x) \|\| 1)` |
| Часов в день | `max(0, min(24, parseFloat(x) \|\| 0))` — **единственное поле с потолком** |
| Тариф | `max(0, parseFloat(x) \|\| 0)` |

Выбранный пресет светильника хранится **отдельным состоянием**, а не выводится из мощности,
и сбрасывается при ручной правке ватт. Это важно: у «LED-панель 60x60» и «Люминесцентная T8»
одинаковые 36 Вт, и сравнение по мощности подсветило бы обе кнопки разом.

## Выходные поля

`requiredLux`, `requiredLumens`, `fixtureLumen`, `fixtureCount`, `fixtureWatt`,
`totalWatt`, `monthlyKwh` (1 знак), `monthlyCost` (0 знаков), `heightCoeff`, `roomName`.

## Замечания к модели

- Месяц жёстко принят за 30 дней.
- Заявленная в маркетинге «световая отдача» ламп накаливания 12 лм/Вт занижена
  относительно реальных ~13–15, люминесцентных 60 — правдоподобно, LED 100 — оптимистично
  для дешёвых серий (реально 80–110).
- Коэффициент высоты — ступенчатый, а не непрерывный: 2.70 м даёт 1.0, а 2.71 м уже 1.2.
  Скачок в 20% на 1 см. При переносе стоит сгладить либо оставить как есть ради
  совпадения цифр с оригиналом.
- Нормы СП в тексте страницы и в калькуляторе расходятся: в тексте есть «Подсобные
  помещения 75 лк», в калькуляторе такого типа нет; зато есть «Гараж 100 лк», которого
  нет в текстовой таблице.
