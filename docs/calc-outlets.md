# Калькулятор розеток и выключателей

**URL:** https://calcal.ru/outlets-switches-calculator
**Чанк с логикой:** `/_next/static/chunks/224b6a5bed7a0453.js` (~39 КБ)
**Снято:** 2026-08-19.

## Что делает

Считает **комплектацию электрофурнитуры на всю квартиру**: сколько розеток, выключателей,
слаботочных точек, подрозетников и рамок нужно, сколько метров кабеля и во что это обойдётся
в трёх ценовых уровнях. Это не однокомнатный калькулятор — он агрегирует по набору комнат.

Логика полностью клиентская, пересчёт в `useEffect` на изменение комнат или ценового уровня.
Сетевых запросов нет.

## Структура ввода

Два уровня:

1. **Глобально:** ценовой уровень — `budget` | `medium` | `premium` (по умолчанию `budget`).
2. **По каждой из 7 комнат** — тумблер «включена» + поля:

| Поле | Тип | Диапазон |
|---|---|---|
| Площадь, м² | number | 1–200 |
| Кол-во комнат (этого типа) | number | 1–10 |
| Силовые розетки 220В | range-слайдер | 0–20 |
| Выключатели | number | 0–10 |
| Проходные выкл. | number | 0–10 |
| USB | number | 0–10 |
| TV | number | 0–5 |
| Интернет | number | 0–5 |

Комнаты: `kitchen`, `living`, `bedroom`, `bathroom`, `hallway`, `nursery`, `office`.
Включены по умолчанию первые пять. Начальное число розеток = `round((outletsMin+outletsMax)/2)`,
остальные поля берутся из пресета как есть. `outletsMin/outletsMax` дальше используются
только как подсказка «Рекомендация: N-M шт.» — на расчёт они не влияют.

## Формула (дословно из бандла)

На каждую **включённую** комнату:

```js
n           = count || 1;                       // сколько таких комнат
outlets     = outlets     * n;
switches    = switches    * n;
passthrough = passthrough * n;
usb         = usb         * n;
tv          = tv          * n;
internet    = internet    * n;

points = outlets + switches + passthrough + usb + tv + internet;

cable  = Math.ceil(points * (4 * Math.sqrt(area) / 4 + 1.5));   // == points * (√area + 1.5)

cost   = outlets * P.outlet
       + (switches + passthrough) * P.switch
       + usb      * P.usbOutlet
       + tv       * P.tvOutlet
       + internet * P.internetOutlet
       + points   * P.frame1
       + points   * P.box;
```

Итоги — простые суммы по комнатам: `totalOutlets`, `totalSwitches` (выключатели + проходные
одной строкой), `totalUsb`, `totalTv`, `totalInternet`, `totalBoxes`, `totalFrames`,
`totalCableMeters`, `totalCost`, плюс `roomBreakdown[]` с разбивкой и `tierLabel`.

## Правила ввода

Как и в калькуляторе освещения, живут в обработчиках полей, а не в расчёте.
Все значения читаются через **`parseInt`**, поэтому дробная часть отбрасывается:
12.9 м² превращается в 12.

| Поле | Правило |
|---|---|
| Площадь | `max(1, parseInt(x) \|\| 1)` |
| Кол-во комнат | `max(1, parseInt(x) \|\| 1)` |
| Выключатели, проходные, USB, TV, интернет | `max(0, parseInt(x) \|\| 0)` |
| Силовые розетки | ползунок `range` 0–20, ограничен самим элементом |

## Замечания к модели

- **`4 * Math.sqrt(area) / 4`** — мёртвая арифметика, тождественно `Math.sqrt(area)`.
  Похоже на остаток правки формулы. Переносить как `√area`.
- **Рамки 2–5 постов не используются.** В прайсе они есть, но расчёт всегда берёт `frame1`
  на каждую точку — то есть модель предполагает, что все точки одинарные. Реальные сборки
  в блоки по 2–4 поста дешевле; это заметное расхождение с практикой и очевидное место,
  где наша версия может быть точнее.
- **`totalBoxes` и `totalFrames` всегда равны** — обе величины это просто число точек.
- **Проходные выключатели считаются по цене обычных** (`P.switch`), хотя стоят дороже.
- **Наценки за влагозащиту (IP44) для ванной нет**, хотя в описании комнаты она заявлена.
- Кабель считается «на точку», без учёта высоты потолка и топологии щита — грубая эвристика.
