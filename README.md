# domeo-calculators

Три разных дела в одном репозитории:

1. **Нормировочная модель электрики и света** — из площади и параметров помещения выводит
   количества розеток, выключателей и светильников. Перенесена из рабочей Excel-таблицы,
   считает библиотека, интерфейс будет отдельный. См. [docs/calc-spec.md](docs/calc-spec.md).
2. **Опросник «Передача проекта в комплектацию»** — то, что сейчас развёрнуто на стенде.
   Дизайнер заполняет и скачивает PDF. См. [docs/handover-form.md](docs/handover-form.md).
3. **Порт калькуляторов с calcal.ru** — освещённость и электрофурнитура. Библиотека
   и тесты остались в репозитории, но со страницы сняты (план поменялся 21.08.2026).

Имя репозитория осталось от третьего пункта.

## Нормировочная модель

Отвечает на вопрос «сколько чего нужно» по планировке и пожеланиям — до того, как появились
чертежи. Цен не считает: это спецификация, а не смета.

Два профиля расчёта. `excel` дословно повторяет исходную таблицу и служит эталоном переноса;
`domeo` — рабочая модель с восстановленным справочником по типам помещений и починенными
местами. Полный список отличий — в [docs/calc-spec.md](docs/calc-spec.md).

Справочник и коэффициенты живут в [data/spec.json](data/spec.json), а не в коде: правка
норматива не требует правки программы.

## Коротко по итогам разведки calcal.ru

Оба калькулятора — клиентские React-компоненты. **API нет, форм нет, сетевых запросов при
расчёте нет.** Вся арифметика и все справочные таблицы зашиты в постраничный JS-чанк
Next.js, оттуда и извлечены.

Парсить по HTML-тегам нечего: у инпутов нет `name`/`id`, варианты выбора — это `<button>`
с различием только в Tailwind-классах. Подробности и устойчивая процедура извлечения —
в [parsing-notes.md](docs/parsing-notes.md).

Объём логики небольшой: ~20 строк арифметики и 3–4 таблицы на калькулятор. Обе формулы
выписаны дословно и лежат в спеках.

## Запуск локально

```bash
dotnet run --project src/Domeo.Calculators.Web
```

Дальше — http://localhost:5099. Считает библиотека на сервере, страница только рисует:
своей копии формул и справочников у неё нет, всё приходит через API.

| Эндпоинт | Что делает |
|---|---|
| `GET /api/spec/reference` | Справочник помещений и коэффициенты — чтобы построить форму |
| `POST /api/spec` | Расчёт спецификации по помещениям |
| `POST /api/report/pdf` | PDF-снимок страницы опросника с заполненными ответами |

Пример расчёта:

```bash
curl -s localhost:5099/api/spec -H "Content-Type: application/json" -d '{
  "profile": "domeo",
  "rooms": [
    { "roomType": "bedroom", "name": "Спальня", "area": 17.5, "comfort": "Standard",
      "tv": 1, "vacuum": true, "downlights": true, "chandelier": true, "sconces": true }
  ]
}'
```

Консольный прогон без браузера:

```bash
dotnet run --project samples/Domeo.Calculators.Demo
```

## Сборка и тесты

```bash
dotnet test Domeo.Calculators.sln
```

Эталоны пересобираются только после правки исходников — `data/*.json` для калькуляторов
calcal, `data/source/*.xlsx` для нормировочной модели:

```bash
node tools/golden/generate.mjs
```

```bash
python tools/golden/generate-spec.py
```
